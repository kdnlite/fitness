# KDN Fitness Android app

Built automatically by `.github/workflows/android.yml` on every push that changes the website or this folder.

- Test APK and Play Store `.aab`: https://github.com/kdnlite/fitness/releases
- Build log: branch `ci-logs`
- Package: `com.kdnfitness.app`
- Signing: `upload-key.jks.enc` is unlocked by the `KDN_KEYSTORE_PASSWORD` repository secret.
